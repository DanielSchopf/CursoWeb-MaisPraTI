# Curso Desenvolvedor Fullstack - MaisPraTi

Este repositório contém as listas de exercícios e atividades do curso Desenvolvedor Fullstack oferecido pela MaisPraTi.

## Estrutura do Projeto

### Módulo 01 e Módulo 02

Para executar as listas de exercícios dos Módulos 01 e 02, você precisará ter as dependências adequadas instaladas. O projeto utiliza a biblioteca `prompt-sync` para entrada de dados via terminal no Node.js.

1. **Certifique-se de que o Node.js está instalado em sua máquina.** Se ainda não o fez, você pode baixá-lo e instalá-lo a partir de [nodejs.org](https://nodejs.org/).

2. **Instale a biblioteca `prompt-sync`** executando o seguinte comando no terminal:

    ```bash
    npm install prompt-sync
    ```

3. **Para executar os exercícios,** navegue até o diretório contendo os arquivos e execute os scripts conforme as instruções fornecidas em cada exercício.

### Módulo 03

Para visualizar e interagir com o projeto do Módulo 03, abra o arquivo `index.html` em um navegador de sua preferência.

### Módulo 04

O Módulo 04 consiste na atualização do código do Módulo 03. Para acessar esta atividade, altere para a branch "Atv04" do repositório. Você pode fazer isso com o seguinte comando:

    ```bash
    git checkout Atv04
    ```

### Módulo 05

As atividades do Módulo 05 requerem a instalação do Java. Certifique-se de que você tem o Java instalado em seu sistema. Se ainda não o fez, você pode baixar e instalar a partir de [oracle.com](https://www.oracle.com/java/technologies/javase-downloads.html) ou [openjdk.java.net](https://openjdk.java.net/install/).
